# 知识库模块 — 文档管理与向量检索

知识库模块负责将 PDF/Markdown 文档转换为向量嵌入，供对话时的 RAG（检索增强生成）使用。

## 一、数据库模型

```prisma
model Document {
  id          String   @id @default(cuid())
  name        String   // 文件名
  content     String?  // 解析后的文本内容
  status      String   // pending → processing → completed → embedding
  format      String   // "pdf" 或 "markdown"
  userId      String
  createdAt   DateTime @default(now())
  updatedAt   DateTime @updatedAt

  user        User          @relation(fields: [userId], references: [id])
  apps        AppDocument[] // 被哪些智能体引用
  chunks      DocumentChunk[] // 分块结果
}

model AppDocument {
  id         String   @id @default(cuid())
  appId      String
  documentId String
  createdAt  DateTime @default(now())

  app        App      @relation(fields: [appId], references: [id], onDelete: Cascade)
  document   Document @relation(fields: [documentId], references: [id], onDelete: Cascade)
}

model DocumentChunk {
  id         String   @id @default(cuid())
  documentId String
  content    String   // 文本片段
  embedding  Float[]  // 768 维向量（nomic-embed-text）
  createdAt  DateTime @default(now())

  document   Document @relation(fields: [documentId], references: [id], onDelete: Cascade)
}
```

### 文档状态流转

```
上传 → pending → processing → completed → embedding
                      ↘ error ↗
```

| 状态 | 含义 |
|------|------|
| pending | 已上传，等待解析 |
| processing | 正在解析 |
| completed | 解析完成，文本已提取 |
| embedding | 已向量化（可用于 RAG） |
| error | 解析失败 |

### 检索流程

```
用户输入问题 → 点击搜索
  ↓
POST /api/embeddings
  { query: "问题", topK: 10, threshold: 0.3 }
  ↓
后端：
  1. 将问题文本向量化 (getEmbedding)
  2. 查询所有 DocumentChunk（含 embedding）
  3. 计算 query 向量与每个 chunk 的余弦相似度
  4. 过滤 < threshold 的结果
  5. 按相似度降序排序
  6. 取 top K
  ↓
返回结果数组（文档名、相似度、内容片段）
```

## 六、核心工具库

### 6.1 文本分块 — `src/lib/chunking.ts`

```typescript
interface TextChunk {
  content: string;    // 文本内容
  metadata: {
    chunkIndex: number;
    documentSource?: string;
    wordCount: number;
    tokenCount: number; // 估算：content.length / 4
  };
}

interface ChunkConfig {
  chunkSize: number;   // 默认 1000 字符
  overlap: number;     // 默认 200 字符重叠
  minLength: number;   // 默认 100 字符最小长度
}
```

### 分块算法

```
输入文本
  ↓
1. 按双换行符 (\n\n) 分割为段落
  ↓
2. 对每个段落：
   a. 如果段落长度 <= chunkSize → 直接作为一块
   b. 如果段落长度 > chunkSize → 按句子（句号/问号/感叹号）分割
  ↓
3. 合并短句直到接近 chunkSize
  ↓
4. 每块添加 overlap 字符的重叠（来自下一块的开头）
  ↓
5. 过滤掉 < minLength 的块
  ↓
6. 为每块添加 metadata（索引、来源文档名、词数、Token估算）
```

### 增强上下文

```typescript
function enhanceChunkWithContext(
  chunk: TextChunk,
  documentName: string
): TextChunk {
  // 在 chunk 内容前添加文档来源上下文
  chunk.content = `[来源: ${documentName}]\n\n${chunk.content}`;
  return chunk;
}
```

这使得 AI 在 RAG 检索结果中能看到引用来源。

```typescript
const EMBEDDING_MODEL = process.env.OLLAMA_EMBEDDING_MODEL || "nomic-embed-text";

// 余弦相似度计算
export function cosineSimilarity(a: number[], b: number[]): number {
  const dotProduct = a.reduce((sum, v, i) => sum + v * b[i], 0);
  const normA = Math.sqrt(a.reduce((sum, v) => sum + v * v, 0));
  const normB = Math.sqrt(b.reduce((sum, v) => sum + v * v, 0));
  return dotProduct / (normA * normB);
}
```

### 相似度含义

| 余弦相似度 | 含义 |
|-----------|------|
| 1.0 | 完全相同 |
| 0.8 - 1.0 | 高度相关 |
| 0.5 - 0.8 | 中等相关 |
| 0.3 - 0.5 | 弱相关 |
| < 0.3 | 不相关（默认阈值过滤） |

### 文档管理 API

| 方法 | 路径 | 功能 |
|------|------|------|
| GET | `/api/documents` | 获取当前用户的文档列表 |

### 向量化 API

| 方法 | 路径 | 功能 |
|------|------|------|
| POST | `/api/embeddings` | 向量检索：输入问题 → 返回最相关的文档片段 |
| POST | `/api/embeddings/process/[id]` | 处理文档：分块 + 向量化 + 存入 DocumentChunk |

### 文档上传 API 详解

```typescript
// POST /api/documents（FormData）

const file = formData.get("file") as File;

// 1. 验证
if (!file.name.endsWith(".pdf") && !file.name.endsWith(".md")) {
  return { error: "仅支持 PDF 和 Markdown 格式" };
}
if (file.size > 10 * 1024 * 1024) {
  return { error: "文件大小不能超过 10MB" };
}

// 2. 保存到磁盘
const filename = `${Date.now()}-${file.name}`;
const filepath = path.join(process.cwd(), "uploads/documents", filename);
await fs.writeFile(filepath, Buffer.from(await file.arrayBuffer()));

// 3. 创建数据库记录
const document = await prisma.document.create({
  data: {
    name: file.name,
    format: file.name.endsWith(".pdf") ? "pdf" : "markdown",
    status: "pending",
    userId,
  },
});

// 4. 异步解析（不阻塞响应）
processDocument(document.id, filepath);

return document;
```

### 文档向量化 API 详解

```typescript
// POST /api/embeddings/process/[id]

// 1. 读取文档内容
let content: string;
if (document.format === "pdf") {
  const pdfData = await pdfParse(fs.readFileSync(filepath));
  content = pdfData.text;
} else {
  content = fs.readFileSync(filepath, "utf-8");
}

// 2. 更新文档状态
await prisma.document.update({
  where: { id },
  data: { content, status: "processing" },
});

// 3. 分块
const chunks = chunkText(content, { chunkSize: 1000, overlap: 200 });
const enhancedChunks = chunks.map((c) =>
  enhanceChunkWithContext(c, document.name)
);

// 4. 批量向量化（每次最多 5 个，避免 Ollama 过载）
for (let i = 0; i < enhancedChunks.length; i += 5) {
  const batch = enhancedChunks.slice(i, i + 5);
  const texts = batch.map((c) => c.content);
  const embeddings = await getEmbeddings(texts);

  await prisma.documentChunk.createMany({
    data: batch.map((chunk, j) => ({
      documentId: id,
      content: chunk.content,
      embedding: embeddings[j],
    })),
  });
}

// 5. 完成
await prisma.document.update({
  where: { id },
  data: { status: "embedding" },
});
```

## 八、与其他模块的关系

```
知识库 (Knowledge Base)
  │
  ├── Document（文档）
  │     ├── 上传 → PDF/MD 文件保存到磁盘
  │     ├── 解析 → 提取纯文本
  │     ├── 分块 → chunkText() 切分为片段
  │     └── 向量化 → getEmbeddings() 生成 768 维向量
  │
  ├── DocumentChunk（向量片段）
  │     ├── content → 文本片段（含来源标注）
  │     ├── embedding → 768 维向量
  │     └── 用于余弦相似度匹配
  │
  ├── AppDocument（关联表）
  │     └── 将智能体与文档关联 → 对话时自动检索
  │
  └── 被对话模块使用
        └── POST /api/chat → RAG 检索 → 增强 System Prompt
```

### 完整的 RAG 流程

```
用户提问: "什么是 Docker？"
  ↓
1. 获取智能体关联的所有文档
  ↓
2. 将问题向量化 → [0.12, -0.34, ..., 0.56]  (768 维)
  ↓
3. 查询所有 DocumentChunk，计算余弦相似度
  ↓
4. 取相似度 > 0.3 的 top 5 片段
  ↓
5. 构建增强 System Prompt:
   """
   你是一个有帮助的AI助手。

   以下是参考资料：
   [来源: Docker入门.pdf]
   Docker 是一个容器化平台...

   [来源: 容器技术.md]
   容器技术是一种轻量级虚拟化...
   """
  ↓
6. 调用 Ollama，带着增强后的 System Prompt 回答
  ↓
7. 流式返回 AI 回复，附带引用标签
```
