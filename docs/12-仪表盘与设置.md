### 最近活动

活动数据来自 `GET /api/dashboard/stats` 的 `activities` 数组，合并自三张表：

```typescript
// 后端合并逻辑
const [chats, apps, workflows] = await Promise.all([
  prisma.chat.findMany({ take: 5, orderBy: { updatedAt: "desc" } }),
  prisma.app.findMany({ take: 5, orderBy: { updatedAt: "desc" } }),
  prisma.workflow.findMany({ take: 5, orderBy: { updatedAt: "desc" } }),
]);

// 合并为统一格式的活动记录
const activities = [
  ...chats.map((c) => ({ type: "chat", title: c.title, timestamp: c.updatedAt })),
  ...apps.map((a) => ({ type: "app", title: a.name, timestamp: a.updatedAt })),
  ...workflows.map((w) => ({ type: "workflow", title: w.name, timestamp: w.updatedAt })),
].sort((a, b) => b.timestamp - a.timestamp).slice(0, 10);
```

## 五、设置模块的关系

```
settings/page.tsx (系统设置)
  ├── useThemeStore → 主题切换按钮
  ├── GET /api/settings/status → Ollama 状态 + 统计数据
  └── 只读展示，不修改数据

settings/account.tsx (账户设置)
  ├── PATCH /api/auth/profile → 修改名称/密码
  └── 修改用户信息

settings/profile.tsx (个人资料)
  ├── GET /api/auth/me → 用户信息
  ├── GET /api/user/stats → 个人统计
  └── 只读展示 + ID 复制
```

三个子页面各司其职：
- **系统设置**: 平台级配置（Ollama、主题）
- **账户设置**: 个人信息修改（名称、密码）
- **个人资料**: 个人信息查看（头像、统计、详情）
