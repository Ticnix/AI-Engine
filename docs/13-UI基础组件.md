# UI 基础组件

本项目使用 shadcn/ui + base-ui 作为基础 UI 组件库。这些组件通过 `class-variance-authority` (CVA) 实现样式变体，通过 `tailwind-merge` 实现类名合并。

## 一、配置 — `components.json`

```json
{
  "style": "base-nova",
  "tsx": true,
  "tailwind": {
    "config": "",
    "css": "src/app/globals.css",
    "baseColor": "neutral",
    "cssVariables": true
  },
  "aliases": {
    "utils": "@/lib/utils",
    "components": "@/components",
    "ui": "@/components/ui"
  }
}
```

- **style**: `base-nova` — base-ui 的 Nova 风格
- **path alias**: `@/*` → `./src/*`
- **RSC 支持**: `tsx: true`

## 二、Button — `src/components/ui/button.tsx`

```typescript
import { Button as ButtonPrimitive } from "@base-ui/react/button";
import { cva, type VariantProps } from "class-variance-authority";
import { cn } from "@/lib/utils";

const buttonVariants = cva(
  // 基础样式
  "inline-flex items-center justify-center gap-2 whitespace-nowrap rounded-md text-sm font-medium transition-[color,box-shadow] disabled:pointer-events-none disabled:opacity-50 [&_svg]:pointer-events-none [&_svg:not([class*='size-'])]:size-4 shrink-0 [&_svg]:shrink-0 cursor-pointer",
  {
    variants: {
      variant: {
        default: "bg-primary text-primary-foreground hover:bg-primary/90",
        outline: "border border-input bg-background hover:bg-accent hover:text-accent-foreground",
        secondary: "bg-secondary text-secondary-foreground hover:bg-secondary/80",
        ghost: "hover:bg-accent hover:text-accent-foreground",
        destructive: "bg-destructive text-destructive-foreground hover:bg-destructive/90",
        link: "text-primary underline-offset-4 hover:underline",
      },
      size: {
        default: "h-9 px-4 py-2 has-[>svg]:px-3",
        xs: "h-7 rounded px-2 has-[>svg]:px-2.5",
        sm: "h-8 rounded-md gap-1.5 px-3 has-[>svg]:px-2.5",
        lg: "h-10 rounded-md px-6 has-[>svg]:px-4",
        icon: "size-9",
      },
    },
    defaultVariants: {
      variant: "default",
      size: "default",
    },
  }
);

function Button({ className, variant, size, ...props }) {
  return (
    <ButtonPrimitive
      className={cn(buttonVariants({ variant, size, className }))}
      {...props}
    />
  );
}

export { Button, buttonVariants };
```

### 变体说明

| variant | 场景 |
|---------|------|
| default | 主要操作（蓝色背景白字） |
| outline | 次要操作（边框+透明背景） |
| secondary | 次级主要操作（灰色背景） |
| ghost | 无背景，仅悬停高亮 |
| destructive | 危险操作（红色背景） |
| link | 文字链接（下划线） |

### 尺寸说明

| size | 高度 | 场景 |
|------|------|------|
| xs | 28px | 表格内小按钮 |
| sm | 32px | 工具栏按钮 |
| default | 36px | 一般按钮 |
| lg | 40px | 突出按钮 |
| icon | 36×36 | 纯图标按钮 |

### 使用示例

```typescript
<Button variant="default" size="default">提交</Button>
<Button variant="outline" size="sm">取消</Button>
<Button variant="destructive" size="xs">删除</Button>
<Button variant="ghost" size="icon">🔍</Button>
```

## 三、Input — `src/components/ui/input.tsx`

```typescript
import { Input as InputPrimitive } from "@base-ui/react/input";
import { cn } from "@/lib/utils";

function Input({ className, type, ...props }) {
  return (
    <InputPrimitive
      type={type}
      className={cn(
        "flex h-9 w-full rounded-md border border-input bg-transparent px-3 py-1 text-sm shadow-xs transition-[color,box-shadow] file:border-0 file:bg-transparent file:text-sm file:font-medium file:text-foreground placeholder:text-muted-foreground focus-visible:outline-none focus-visible:ring-[3px] focus-visible:ring-ring/20 disabled:cursor-not-allowed disabled:opacity-50 md:text-sm",
        className
      )}
      {...props}
    />
  );
}

export { Input };
```

### 样式特征

- **高度**: 36px (`h-9`)
- **圆角**: `rounded-md`
- **聚焦**: `focus-visible:ring-[3px]` — 3px 宽的聚焦环
- **文件上传**: 支持 `<input type="file">`，文件选择器无额外边框
- **禁用**: `disabled:opacity-50` + `cursor-not-allowed`

## 四、Label — `src/components/ui/label.tsx`

```typescript
function Label({ className, ...props }) {
  return (
    <label
      className={cn(
        "flex items-center gap-2 text-sm leading-none font-medium select-none",
        "peer-disabled:cursor-not-allowed peer-disabled:opacity-50",
        "group-disabled:cursor-not-allowed group-disabled:opacity-50",
        className
      )}
      {...props}
    />
  );
}

export { Label };
```

- **peer-disabled**: 当关联的 input 禁用时，label 也变灰
- **group-disabled**: 在表单组禁用时自动变灰

### 与 Ant Design 的关系

项目中有两套 UI 组件并存：

| 场景 | 使用的 UI 库 |
|------|-------------|
| 表单、表格、弹窗、菜单等复杂组件 | Ant Design 6 |
| 基础按钮、输入框、标签等简单组件 | shadcn/base-ui |

这样做的原因：
- **Ant Design** 提供了丰富的业务组件（Table、Form、Modal 等），节省开发时间
- **shadcn/base-ui** 提供了更灵活的样式控制，方便定制

两者不冲突，可以在同一页面中混合使用。
