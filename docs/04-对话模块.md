# 对话模块 — AI 流式对话

对话模块是用户与 AI 智能体交互的核心界面。支持多轮对话历史、SSE 流式响应、RAG 检索增强生成、以及引用来源展示。

## 一、数据库模型

```prisma
model Chat {
  id          String   @id @default(cuid())
  title       String
  appId       String   // 所属智能体
  createdAt   DateTime @default(now())
  updatedAt   DateTime @updatedAt

  // 统计信息
  totalTokens  Int     @default(0)  // 总 Token 数
  inputTokens  Int     @default(0)  // 输入 Token 数
  outputTokens Int     @default(0)  // 输出 Token 数

  app         App       @relation(fields: [appId], references: [id])
  messages    Message[]
}

model Message {
  id        String   @id @default(cuid())
  chatId    String
  role      String   // "user" 或 "assistant"
  content   String
  createdAt DateTime @default(now())

  chat      Chat     @relation(fields: [chatId], references: [id])
}
```

### 核心流程

```
1. 页面加载
   - 从 URL 参数获取 appId 或 chatId
   - 如果有 chatId → 加载历史消息 (GET /api/chats/[id]/messages)
   - 如果有 appId → 加载智能体信息并设为当前智能体

2. 用户发送消息
   - MessageInput 输入文字，按 Enter 发送
   - 将用户消息追加到 messages 列表
   - POST /api/chat 发送请求

3. 接收 SSE 流式响应
   - 创建 EventSource 连接到 /api/chat
   - 逐行解析 "data:" 开头的 SSE 数据
   - type: "token" → 追加到当前 AI 消息的 content
   - type: "done" → 标记完成，保存 chatId 和 references
   - type: "error" → 显示错误

4. 自动滚动
   - 每次消息更新后，scrollToBottom() 滚动到最新消息
```

### SSE 流式处理代码片段

```typescript
const handleSend = async (content: string) => {
  // 添加用户消息到列表
  const userMessage = { role: "user", content, id: `user-${Date.now()}` };
  setMessages((prev) => [...prev, userMessage]);

  // 创建占位 AI 消息
  const aiMessageId = `ai-${Date.now()}`;
  setMessages((prev) => [
    ...prev,
    { role: "assistant", content: "", id: aiMessageId },
  ]);

  // 发送请求
  const response = await fetch("/api/chat", {
    method: "POST",
    headers: { "Content-Type": "application/json" },
    body: JSON.stringify({
      appId,
      chatId,
      messages: [...messages, userMessage].map((m) => ({
        role: m.role,
        content: m.content,
      })),
    }),
  });

  // 读取 SSE 流
  const reader = response.body?.getReader();
  const decoder = new TextDecoder();
  let aiContent = "";

  while (true) {
    const { done, value } = await reader.read();
    if (done) break;

    const chunk = decoder.decode(value, { stream: true });
    const lines = chunk.split("\n");

    for (const line of lines) {
      if (line.startsWith("data: ")) {
        const data = JSON.parse(line.slice(6));

        if (data.type === "token") {
          // 增量追加
          aiContent += data.content;
          setMessages((prev) =>
            prev.map((m) =>
              m.id === aiMessageId ? { ...m, content: aiContent } : m
            )
          );
          scrollToBottom();
        } else if (data.type === "done") {
          // 对话完成
          setChatId(data.chatId);
          setReferences(data.references || []);
        } else if (data.type === "error") {
          message.error(data.message);
        }
      }
    }
  }
};
```

## 六、核心 API — POST /api/chat

### 请求体

```json
{
  "appId": "clxxx...",
  "chatId": "clxxx...",     // 可选，新建对话时不传
  "messages": [
    { "role": "user", "content": "你好" },
    { "role": "assistant", "content": "你好！" },
    { "role": "user", "content": "介绍一下你自己" }
  ]
}
```

### 执行流程（重点）

```
1. 验证 App 存在且属于当前用户
   ↓
2. 检查 Ollama 服务状态
   - 如果未运行 → 返回模拟响应（fallback）
   ↓
3. 处理对话
   - 如果有 chatId → 加载已有对话
   - 如果没有 → 创建新 Chat 记录
   ↓
4. 保存用户消息到数据库
   ↓
5. RAG 检索增强（如果智能体绑定了知识库文档）
   - 获取所有关联文档的 DocumentChunk
   - 将用户最新消息向量化
   - 计算余弦相似度，筛选 top K 相关片段
   - 拼接到系统提示词中作为上下文
   ↓
6. 如果智能体绑定了工作流
   - 执行工作流引擎
   - 流式返回工作流输出
   - 如果工作流无输出 → 降级为普通 LLM 对话
   ↓
7. 普通 LLM 对话
   - 构建 messages 数组：[system_prompt, ...history, user_message]
   - 调用 Ollama streamChat
   - 逐 chunk 返回给前端（type: "token"）
   ↓
8. 完成
   - 保存 AI 回复到数据库
   - 更新 Token 统计
   - 发送 type: "done" 事件（含 chatId 和 references）
```

### SSE 响应格式

```
data: {"type":"token","content":"你"}
data: {"type":"token","content":"好"}
data: {"type":"token","content":"！"}
data: {"type":"done","chatId":"clxxx","references":["文档A","文档B"]}
```

## 七、对话 API 接口总览

| 方法 | 路径 | 功能 |
|------|------|------|
| GET | `/api/chats` | 获取当前用户的对话列表（含智能体信息和消息数） |
| GET | `/api/chats/[id]` | 获取对话详情（含智能体信息和消息列表） |
| DELETE | `/api/chats/[id]` | 删除对话（校验所有权） |
| GET | `/api/chats/[id]/messages` | 获取对话的所有消息 |
| POST | `/api/chat` | 核心对话接口（SSE 流式、RAG、工作流） |

## 八、与其他模块的关系

```
对话 (Chat)
  │
  ├── 所属智能体 (appId)
  │     ├── 系统提示词 → 作为 system message 注入
  │     ├── 模型选择 → 决定 Ollama 调用哪个模型
  │     ├── 知识库关联 → RAG 检索增强上下文
  │     └── 工作流绑定 → 执行工作流代替普通对话
  │
  ├── 消息列表 (Message[])
  │     └── 轮流存储 user/assistant 消息
  │
  ├── Token 统计
  │     ├── totalTokens → 总消耗
  │     ├── inputTokens → 输入量
  │     └── outputTokens → 输出量
  │
  └── Ollama 服务
        └── 流式返回 AI 生成内容
```
