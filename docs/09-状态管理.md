# 状态管理模块

本项目使用 Zustand 进行客户端状态管理。Zustand 是一个轻量级状态管理库，相比 Redux 更简单，不需要 Provider 包裹。

## 一、认证状态 — `src/stores/auth-store.ts`

### 完整代码

```typescript
import { create } from "zustand";
import { api } from "@/lib/request";

interface User {
  id: string;
  email: string;
  name: string;
  createdAt: string;
}

interface AuthState {
  // 状态
  user: User | null;
  isLoading: boolean;

  // 操作
  checkAuth: () => Promise<User | null>;
  logout: () => Promise<void>;
  setUser: (user: User) => void;
  setLoading: (loading: boolean) => void;
}

export const useAuthStore = create<AuthState>((set) => ({
  // 初始状态
  user: null,
  isLoading: false,

  // 检查登录态
  checkAuth: async () => {
    set({ isLoading: true });
    try {
      const user = await api.get<User>("/api/auth/me");
      set({ user });
      return user;
    } catch {
      set({ user: null });
      return null;
    } finally {
      set({ isLoading: false });
    }
  },

  // 登出
  logout: async () => {
    try {
      await api.post("/api/auth/logout");
    } catch {
      // 忽略服务端错误，仍然清除本地状态
    }
    set({ user: null });
  },

  // 手动设置用户
  setUser: (user) => set({ user }),

  // 设置加载状态
  setLoading: (isLoading) => set({ isLoading }),
}));
```

### 使用场景

| 组件 | 如何使用 |
|------|---------|
| Header | `const { user } = useAuthStore()` — 显示用户名和头像 |
| MainLayout | `const { checkAuth } = useAuthStore()` — 挂载时检查登录态 |
| AuthCard（登录表单） | `const { setUser } = useAuthStore()` — 登录成功后设置用户 |
| Header 的登出按钮 | `const { logout } = useAuthStore()` — 清除认证 |

### 在组件外使用

```typescript
// 在 useEffect 或事件处理函数中
useEffect(() => {
  useAuthStore.getState().checkAuth(); // 不订阅状态变化，只执行一次
}, []);

// 在普通函数中
const handleSomeAction = () => {
  const currentUser = useAuthStore.getState().user;
  if (!currentUser) {
    router.push("/login");
  }
};
```

### 为什么不使用 persist 中间件？

认证状态不持久化到 localStorage。原因：
1. **安全性**: 用户信息不应存储在客户端可访问的存储中
2. **可靠性**: 每次页面加载都通过 `/api/auth/me` 从服务端验证，确保登录态真实有效
3. **Cookie 已持久化**: `auth_session` Cookie 本身可以设置 `maxAge`，无需客户端额外存储

## 二、主题状态 — `src/stores/theme-store.ts`

### 完整代码

```typescript
import { create } from "zustand";
import { persist } from "zustand/middleware";

interface ThemeState {
  mode: "dark" | "light";
  toggleTheme: () => void;
  setTheme: (mode: "dark" | "light") => void;
}

export const useThemeStore = create<ThemeState>()(
  persist(
    (set) => ({
      mode: "dark", // 默认暗色主题

      toggleTheme: () =>
        set((state) => ({
          mode: state.mode === "dark" ? "light" : "dark",
        })),

      setTheme: (mode) => set({ mode }),
    }),
    {
      name: "theme-storage", // localStorage key
    }
  )
);
```

### persist 中间件

`persist` 是 Zustand 的内置中间件，自动将状态同步到 `localStorage`。

```typescript
// 内部原理
// 1. 初始化时从 localStorage.getItem("theme-storage") 读取上次保存的状态
// 2. 每次状态变化时写入 localStorage.setItem("theme-storage", JSON.stringify(state))
// 3. 存储格式: { state: { mode: "dark" }, version: 0 }
```

### 持久化效果

```
用户操作:
  1. 打开页面 → 默认 dark 模式
  2. 点击切换 → light 模式 → 写入 localStorage
  3. 刷新页面 → 从 localStorage 读取 → 仍然是 light 模式
  4. 关闭浏览器再打开 → 仍然保持 light 模式
```

### 主题应用机制

```
useThemeStore (状态变更)
    ↓
ThemeProvider (useLayoutEffect 监听 mode 变化)
    ↓
documentElement.classList.add/remove("light-mode")
documentElement.setAttribute("data-theme", "light|dark")
    ↓
CSS 规则响应
    ↓
Ant Design ConfigProvider (通过 token 适配)
```

## 三、两个 Store 的关系

```
useAuthStore                    useThemeStore
  │                               │
  ├── user: User | null            ├── mode: "dark" | "light"
  ├── isLoading: boolean          ├── toggleTheme()
  ├── checkAuth()                 ├── setTheme()
  ├── logout()                    └── persist → localStorage
  └── setUser()
  │
  └── 不持久化（每次从服务端验证）
```

它们各自独立，互不依赖。认证关注安全性（不持久化到客户端），主题关注用户体验（持久化偏好）。

## 四、Store 在项目中的调用链路

```
页面加载
  │
  ├── MainLayout 组件挂载
  │     └── useAuthStore().checkAuth()
  │           └── GET /api/auth/me
  │                 └── 成功 → set({ user }) → Header 显示用户名
  │                 └── 失败 → set({ user: null }) → (main)/layout.tsx 的 redirect("/login")
  │
  └── ThemeProvider 组件挂载
        └── useThemeStore().mode
              └→ 从 localStorage 读取上次选择
              └→ useLayoutEffect 应用 CSS 类
```
