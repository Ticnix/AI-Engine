# 智能体模块 — AI Agent 管理

智能体（App）是 AI 引擎的核心概念。每个智能体是一个独立的 AI 助手，拥有自己的名称、描述、系统提示词、选择的 LLM 模型，以及可选的知识库绑定。

## 一、数据库模型

```prisma
model App {
  id          String   @id @default(cuid())
  name        String
  description String?
  prompt      String?  // 系统提示词
  model       String   // 使用的 Ollama 模型
  workflowId  String?  // 可选绑定的工作流 ID
  userId      String   // 创建者
  createdAt   DateTime @default(now())
  updatedAt   DateTime @updatedAt

  user        User           @relation(fields: [userId], references: [id])
  chats       Chat[]         // 关联的对话
  workflow    Workflow?      @relation(fields: [workflowId], references: [id])
  documents   AppDocument[]  // 多对多关联知识库文档
}
```

每个智能体可以：
- 绑定多个知识库文档（通过 `AppDocument` 中间表）
- 绑定一个工作流（执行工作流逻辑代替普通对话）
- 拥有多个对话（`Chat` 列表）

## 二、页面路由

| 路由 | 文件 | 功能 |
|------|------|------|
| `/apps` | `src/app/(main)/apps/page.tsx` | 智能体列表 |
| `/apps/new` | `src/app/(main)/apps/new/page.tsx` | 创建新智能体 |
| `/apps/[id]/edit` | `src/app/(main)/apps/[id]/edit/page.tsx` | 编辑智能体 |

## 三、智能体列表页 — `src/app/(main)/apps/page.tsx`

### 完整代码

```typescript
"use client";

import { useEffect, useState } from "react";
import { Table, Button, Tag, Space, Popconfirm, message } from "antd";
import { PlusOutlined, MessageOutlined, EditOutlined, DeleteOutlined } from "@ant-design/icons";
import Link from "next/link";
import { api } from "@/lib/request";

interface AppItem {
  id: string;
  name: string;
  description: string;
  model: string;
  _count: { chats: number };
  createdAt: string;
}

export default function AppsPage() {
  const [apps, setApps] = useState<AppItem[]>([]);
  const [loading, setLoading] = useState(false);

  const fetchApps = async () => {
    setLoading(true);
    try {
      const data = await api.get("/api/apps");
      setApps(data);
    } finally {
      setLoading(false);
    }
  };

  useEffect(() => { fetchApps(); }, []);

  const handleDelete = async (id: string) => {
    try {
      await api.delete(`/api/apps/${id}`);
      message.success("智能体已删除");
      fetchApps();
    } catch (error: any) {
      message.error(error.message);
    }
  };

  const columns = [
    { title: "名称", dataIndex: "name", key: "name" },
    { title: "描述", dataIndex: "description", key: "description" },
    {
      title: "模型",
      dataIndex: "model",
      key: "model",
      render: (model: string) => <Tag color="blue">{model}</Tag>,
    },
    {
      title: "对话数",
      dataIndex: "_count",
      key: "chats",
      render: (count: { chats: number }) => count?.chats || 0,
    },
    { title: "创建时间", dataIndex: "createdAt", key: "createdAt" },
    {
      title: "操作",
      key: "action",
      render: (_: any, record: AppItem) => (
        <Space>
          <Link href={`/apps/${record.id}/edit`}>
            <Button icon={<EditOutlined />} size="small">编辑</Button>
          </Link>
          <Link href={`/chats/new?appId=${record.id}`}>
            <Button icon={<MessageOutlined />} type="primary" size="small">
              对话
            </Button>
          </Link>
          <Popconfirm title="确定要删除吗？" onConfirm={() => handleDelete(record.id)}>
            <Button icon={<DeleteOutlined />} danger size="small">删除</Button>
          </Popconfirm>
        </Space>
      ),
    },
  ];

  return (
    <div>
      <div style={{ marginBottom: 16, display: "flex", justifyContent: "space-between" }}>
        <h2>智能体管理</h2>
        <Link href="/apps/new">
          <Button type="primary" icon={<PlusOutlined />}>新建智能体</Button>
        </Link>
      </div>
      <Table columns={columns} dataSource={apps} rowKey="id" loading={loading} />
    </div>
  );
}
```

### 功能说明

1. **加载数据**: 调用 `GET /api/apps` 获取当前用户的所有智能体
2. **列表展示**: 使用 Ant Design Table，显示名称、描述、模型标签、对话数、创建时间
3. **操作列**:
   - **编辑** → 跳转 `/apps/[id]/edit`
   - **对话** → 跳转 `/chats/new?appId=[id]`（以该智能体创建新对话）
   - **删除** → 弹出确认后调用 `DELETE /api/apps/[id]`

## 四、创建智能体页 — `src/app/(main)/apps/new/page.tsx`

### 表单字段

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| name | Input | 是 | 智能体名称 |
| description | TextArea | 否 | 描述信息 |
| model | Input | 是 | 使用的 Ollama 模型名（如 `qwen2.5:7b`） |
| workflowId | Select | 否 | 绑定的工作流（选中后对话将执行工作流） |

### 提交流程

```
用户点击"创建"
  ↓
收集表单数据 + 选中的 documentIds
  ↓
POST /api/apps
  { name, description, prompt, model, workflowId, documentIds }
  ↓
创建 App 记录
  ↓
循环创建 AppDocument 关联记录
  ↓
返回新建的 App → 跳转 /apps/[id]/edit
```

## 五、编辑智能体页 — `src/app/(main)/apps/[id]/edit/page.tsx`

与新建页类似，区别在于：

1. **加载数据**: 页面挂载时调用 `GET /api/apps/[id]`
2. **预填充表单**: 将返回的 App 数据填入表单
3. **预选中文档**: 从 `app.documents` 中提取已关联的文档 ID，传给 `DocumentSelector`
4. **提交方式**: `PUT /api/apps/[id]`（更新而非创建）

## 六、API 接口

### GET /api/apps — 获取智能体列表

```typescript
// 查询当前用户的所有智能体，附带对话数统计
const apps = await prisma.app.findMany({
  where: { userId },
  include: { _count: { select: { chats: true } } },
  orderBy: { updatedAt: "desc" },
});
```

### POST /api/apps — 创建智能体

```typescript
const app = await prisma.app.create({
  data: {
    name, description, prompt, model, workflowId, userId,
  },
});

// 关联知识库文档
if (documentIds?.length) {
  for (const docId of documentIds) {
    await prisma.appDocument.create({
      data: { appId: app.id, documentId: docId },
    });
  }
}
```

### GET /api/apps/[id] — 获取智能体详情

```typescript
const app = await prisma.app.findUnique({
  where: { id },
  include: {
    chats: { take: 10, orderBy: { updatedAt: "desc" } },
    documents: { include: { document: true } },
  },
});
```

返回智能体的基本信息、最近的 10 个对话、以及关联的文档详情。

### PUT /api/apps/[id] — 更新智能体

更新时处理：
1. 更新 App 基本字段（name, description, prompt, model, workflowId）
2. **文档关联的增量更新**：
   - 删除不再关联的记录（旧 documentIds 中不在新列表中的）
   - 新增关联记录（新 documentIds 中不在旧列表中的）
3. 保留不变的关联

### DELETE /api/apps/[id] — 删除智能体

```typescript
// 权限校验：检查智能体是否属于当前用户
if (app.userId !== userId) {
  return NextResponse.json({ error: "无权操作" }, { status: 403 });
}

// 删除智能体（级联删除关联的 AppDocument）
await prisma.app.delete({ where: { id } });
```

## 七、智能体与对话模块的关系

```
智能体 (App)
  │
  ├── 模型 (model) → 决定使用哪个 Ollama LLM
  │
  ├── 系统提示词 (prompt) → 注入到对话的 System Message
  │
  ├── 知识库 (AppDocument → Document)
  │     └── 对话时进行 RAG 检索，增强上下文
  │
  ├── 工作流 (workflowId → Workflow)
  │     └── 对话时执行工作流逻辑，替代普通 LLM 对话
  │
  └── 对话列表 (Chat[])
        └── 每个对话包含多条 Message
```

智能体是**对话的上下文来源**。当用户在对话页面选择一个智能体后：
1. 系统读取该智能体的 `prompt` 作为 System Message
2. 读取关联的文档，在对话前进行向量检索（RAG）
3. 如果绑定了工作流，则执行工作流而非普通对话

## 八、DocumentSelector 组件 — 知识库文档选择器

### 文件位置
`src/components/document/document-selector.tsx`

### 功能

在创建/编辑智能体时使用的文档选择器。将所有文档分为两组：

1. **已关联的文档** — 当前智能体已绑定的知识库文档（预选中状态）
2. **其他文档** — 用户拥有的其他文档（未选中状态）

### 交互特性

- **搜索过滤**: 顶部搜索框，按文档名称过滤
- **批量操作**: 每组都有"全选/取消"按钮
- **选中切换**: 点击文档卡片切换选中/取消状态
- **向量化状态**: 显示文档的向量化进度标签（pending/processing/completed/embedding/error）
- **主题适配**: 通过 `useThemeStore` 适配亮色/暗色主题
- **底部摘要**: 选中至少一个文档时，底部显示已选数量摘要条

### 返回值

组件是受控组件，通过 `value`（已选 ID 数组）和 `onChange`（变化回调）与父组件通信。
