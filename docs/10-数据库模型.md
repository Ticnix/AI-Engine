# 数据库模型

项目使用 Prisma ORM 管理 PostgreSQL 数据库。Schema 文件位于 `prisma/schema.prisma`。

## 一、数据库配置

```prisma
generator client {
  provider = "prisma-client-js"
}

datasource db {
  provider = "postgresql"
  url      = env("DATABASE_URL")
  relationMode = "prisma"
}
```

- **数据库**: PostgreSQL
- **连接方式**: 通过 `DATABASE_URL` 环境变量
- **关联模式**: `prisma`（Prisma 外键管理，不依赖数据库级外键约束）
- **适配器**: `@prisma/adapter-pg`（用于 Next.js 兼容性）

## 二、10 个数据模型

### 2.1 User — 用户

```prisma
model User {
  id        String    @id @default(cuid())
  email     String    @unique          // 唯一邮箱
  name      String?                    // 显示名称
  password  String                     // bcrypt 哈希
  createdAt DateTime  @default(now())
  updatedAt DateTime  @updatedAt

  apps      App[]
  chats     Chat[]      // 通过 App 间接关联
  documents Document[]
  workflows Workflow[]
}
```

| 字段 | 类型 | 说明 |
|------|------|------|
| id | String | CUID 自动生成，无需手动设置 |
| email | String | 唯一约束，用于登录 |
| name | String? | 可空的显示名称 |
| password | String | bcrypt 哈希（盐轮数 10） |

### 2.2 App — 智能体

```prisma
model App {
  id          String   @id @default(cuid())
  name        String
  description String?
  prompt      String?  @db.Text   // 系统提示词
  model       String              // Ollama 模型名
  workflowId  String?             // 绑定的工作流
  userId      String
  createdAt   DateTime @default(now())
  updatedAt   DateTime @updatedAt

  user        User          @relation(fields: [userId], references: [id])
  chats       Chat[]
  workflow    Workflow?     @relation(fields: [workflowId], references: [id])
  documents   AppDocument[]
}
```

### 2.3 Chat — 对话

```prisma
model Chat {
  id           String   @id @default(cuid())
  title        String
  appId        String
  createdAt    DateTime @default(now())
  updatedAt    DateTime @updatedAt

  totalTokens  Int      @default(0)
  inputTokens  Int      @default(0)
  outputTokens Int      @default(0)

  app          App      @relation(fields: [appId], references: [id])
  messages     Message[]
}
```

### 2.4 Message — 消息

```prisma
model Message {
  id        String   @id @default(cuid())
  chatId    String
  role      String   // "user" 或 "assistant"
  content   String   @db.Text
  createdAt DateTime @default(now())

  chat      Chat     @relation(fields: [chatId], references: [id])
}
```

### 2.5 Document — 知识库文档

```prisma
model Document {
  id        String   @id @default(cuid())
  name      String   // 文件名
  content   String?  @db.Text  // 解析后的文本
  status    String   // pending/processing/completed/embedding/error
  format    String   // "pdf" 或 "markdown"
  userId    String
  createdAt DateTime @default(now())
  updatedAt DateTime @updatedAt

  user      User          @relation(fields: [userId], references: [id])
  apps      AppDocument[]
  chunks    DocumentChunk[]
}
```

### 2.6 AppDocument — 智能体-文档关联（多对多中间表）

```prisma
model AppDocument {
  id         String   @id @default(cuid())
  appId      String
  documentId String
  createdAt  DateTime @default(now())

  app        App      @relation(fields: [appId], references: [id], onDelete: Cascade)
  document   Document @relation(fields: [documentId], references: [id], onDelete: Cascade)
}
```

### 2.7 DocumentChunk — 文档分块（向量存储）

```prisma
model DocumentChunk {
  id         String   @id @default(cuid())
  documentId String
  content    String   @db.Text   // 文本片段
  embedding  Float[]             // 768 维向量
  createdAt  DateTime @default(now())

  document   Document @relation(fields: [documentId], references: [id], onDelete: Cascade)
}
```

**注意**: `embedding` 字段使用 PostgreSQL 数组类型（`Float[]`）。向量相似度查询需要在数据库层面进行计算。

### 2.8 Workflow — 工作流

```prisma
model Workflow {
  id          String   @id @default(cuid())
  name        String
  description String?
  nodes       Json              // React Flow 节点定义
  edges       Json              // React Flow 连线定义
  status      String   // draft/published/archived
  userId      String
  createdAt   DateTime @default(now())
  updatedAt   DateTime @updatedAt

  user        User             @relation(fields: [userId], references: [id])
  apps        App[]
  executions  WorkflowExecution[]
}
```

**JSON 字段**: `nodes` 和 `edges` 存储为 JSON 格式，包含 React Flow 的完整画布状态。这使得工作流定义可以被序列化和还原。

### 2.9 WorkflowExecution — 工作流执行记录

```prisma
model WorkflowExecution {
  id          String   @id @default(cuid())
  workflowId  String
  status      String   // running/success/error/cancelled
  input       Json?
  output      Json?
  error       String?
  startedAt   DateTime @default(now())
  completedAt DateTime?

  workflow    Workflow       @relation(fields: [workflowId], references: [id])
  nodeExecutions NodeExecution[]
}
```

### 2.10 NodeExecution — 节点执行详情

```prisma
model NodeExecution {
  id          String   @id @default(cuid())
  executionId String
  nodeId      String
  nodeType    String
  status      String   // running/success/error/skipped
  input       Json?
  output      Json?
  error       String?
  startedAt   DateTime @default(now())
  completedAt DateTime?

  execution   WorkflowExecution @relation(fields: [executionId], references: [id])
}
```

```

 │     │     └── Message (1:N)

 │     │     └── Document

 │
 ├── Document (1:N)
 │     └── AppDocument (M:N)

             └── NodeExecution (1:N)
```

## 四、关键索引与约束

### 唯一约束

| 模型 | 字段 | 用途 |
|------|------|------|
| User | email | 确保邮箱唯一，用于登录 |

### 外键关系

| 从 | 到 | 级联 |
|---|---|------|
| App.userId | User.id | — |
| App.workflowId | Workflow.id | 可空，不级联 |
| Chat.appId | App.id | — |
| Message.chatId | Chat.id | — |
| Document.userId | User.id | — |
| AppDocument.appId | App.id | 级联删除 |
| AppDocument.documentId | Document.id | 级联删除 |
| DocumentChunk.documentId | Document.id | 级联删除 |
| Workflow.userId | User.id | — |
| WorkflowExecution.workflowId | Workflow.id | — |
| NodeExecution.executionId | WorkflowExecution.id | — |

### 级联删除规则

- 删除 App → 不级联删除 Chat（需要手动处理）
- 删除 App → 级联删除 AppDocument 关联
- 删除 Document → 级联删除 AppDocument + DocumentChunk
- 删除 Workflow → 不级联删除 executions（保留执行历史）

## 五、数据库操作示例

### 查询智能体及其关联

```prisma
// 获取用户的智能体，附带对话数和关联文档
prisma.app.findMany({
  where: { userId },
  include: {
    _count: { select: { chats: true } },
    documents: { include: { document: true } },
  },
  orderBy: { updatedAt: "desc" },
});
```

### 查询对话及消息

```prisma
// 获取对话详情，含智能体信息和消息列表
prisma.chat.findUnique({
  where: { id },
  include: {
    app: true,
    messages: { orderBy: { createdAt: "asc" } },
  },
});
```

### RAG 检索

```prisma
// 查询某个智能体的所有关联文档的分块
const chunks = await prisma.documentChunk.findMany({
  where: {
    document: {
      apps: { some: { appId } },
    },
  },
  select: { id: true, content: true, embedding: true },
});

// 然后计算每个 chunk 与 query 向量的余弦相似度
```

### 工作流执行历史

```prisma
// 获取工作流的最近执行记录
prisma.workflowExecution.findMany({
  where: { workflowId },
  include: {
    nodeExecutions: { orderBy: { startedAt: "asc" } },
  },
  orderBy: { startedAt: "desc" },
  take: 50,
});
```

## 六、迁移管理

```bash
# 生成迁移（schema 变更后）
npx prisma migrate dev --name "描述性名称"

# 应用迁移到生产
npx prisma migrate deploy

# 重置数据库（开发环境）
npx prisma migrate reset

# 查看迁移状态
npx prisma migrate status
```

### 配置文件 — `prisma.config.ts`

```typescript
import { defineConfig } from "prisma/config";

export default defineConfig({
  schema: "prisma/schema.prisma",
  migrations: {
    path: "prisma/migrations",
  },
  datasource: {
    url: process.env.DATABASE_URL,
  },
});
```

这是 Prisma 的新配置格式（替代 `prisma` 字段在 `package.json` 中的配置）。
