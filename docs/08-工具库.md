# 工具库模块

本模块包含项目中所有共享的工具函数和库封装，分布在 `src/lib/` 目录下。

## 一、通用工具 — `src/lib/utils.ts`

```typescript
import { clsx, type ClassValue } from "clsx";
import { twMerge } from "tailwind-merge";

export function cn(...inputs: ClassValue[]) {
  return twMerge(clsx(inputs));
}
```

### 作用

这是 shadcn/ui 标准的 `cn` 函数，用于合并 Tailwind CSS 类名。

### 为什么需要？

Tailwind 的类名如果冲突，后面的会覆盖前面的。但有时动态拼接会导致类名重复或冲突。`cn` 函数通过两个步骤解决这个问题：

1. `clsx(inputs)` — 过滤 falsy 值，拼接类名字符串
2. `twMerge(...)` — 智能合并 Tailwind 类名，处理冲突（如 `p-4` 和 `p-6` 只保留后者）

### 使用示例

```typescript
// 基础用法
className={cn("flex items-center", isActive && "bg-blue-500", className)}

// 如果 className = "p-4"，且 isActive = true：
// → "flex items-center bg-blue-500 p-4"
// 如果 className = "p-6"（与前面的 p-4 冲突）：
// → "flex items-center bg-blue-500 p-6"（twMerge 自动解决冲突）
```

## 二、请求封装 — `src/lib/request.ts`

### 完整代码

```typescript
// 通用 fetch 封装
async function request<T>(
  url: string,
  options?: { method?: string; body?: any; headers?: Record<string, string> }
): Promise<T> {
  const method = options?.method || "GET";
  const headers = { "Content-Type": "application/json", ...options?.headers };
  let body = options?.body;

  if (body && typeof body === "object" && !(body instanceof FormData)) {
    body = JSON.stringify(body);
  }

  const response = await fetch(url, { method, headers, body });

  if (!response.ok) {
    const error = await response.json().catch(() => ({}));
    throw new Error(error.message || error.error || `请求失败: ${response.status}`);
  }

  // 204 No Content
  if (response.status === 204) return undefined as T;

  return response.json();
}

// 便捷方法
export function uploadFile(url: string, formData: FormData): Promise<any> {
  return request(url, {
    method: "POST",
    body: formData,
    headers: {}, // 不要设置 Content-Type，让浏览器自动设置 boundary
  });
}

// API 对象 — 提供 RESTful 风格的调用
export const api = {
  get: <T>(url: string) => request<T>(url, { method: "GET" }),
  post: <T>(url: string, body?: any) => request<T>(url, { method: "POST", body }),
  put: <T>(url: string, body?: any) => request<T>(url, { method: "PUT", body }),
  patch: <T>(url: string, body?: any) => request<T>(url, { method: "PATCH", body }),
  delete: <T>(url: string) => request<T>(url, { method: "DELETE" }),
  upload: (url: string, formData: FormData) => uploadFile(url, formData),
};
```

### 设计特点

| 特性 | 说明 |
|------|------|
| 自动序列化 | 普通对象自动 `JSON.stringify`，`FormData` 原样传递 |
| 统一错误处理 | `response.ok` 为 false 时抛出 Error，包含后端错误信息 |
| TypeScript 泛型 | `api.get<User[]>(...)` 直接返回类型化的结果 |
| 204 处理 | 正确处理 No Content 响应 |
| FormData 特殊处理 | 上传文件时不设置 `Content-Type`，让浏览器自动设置 `multipart/form-data` 的 boundary |

### 调用示例

```typescript

// POST — 创建对话
```

## 三、Prisma 客户端 — `src/lib/prisma.ts`

```typescript
import { PrismaClient } from "@prisma/client";
import { PrismaPg } from "@prisma/adapter-pg";
import pg from "pg";

const { Pool } = pg;

const globalForPrisma = globalThis as unknown as {
  pool: ReturnType<typeof globalThis.pools> | null;
  prisma: PrismaClient | undefined;
};

// 创建连接池（全局单例）
const pool = globalForPrisma.pool || new Pool({
  connectionString: process.env.DATABASE_URL,
});
if (process.env.NODE_ENV !== "production") globalForPrisma.pool = pool;

// 创建 Prisma 客户端（开发环境防止热重载重复实例化）
const adapter = new PrismaPg(pool);
export const prisma = globalForPrisma.prisma || new PrismaClient({ adapter });
if (process.env.NODE_ENV !== "production") globalForPrisma.prisma = prisma;
```

### 关键设计

**为什么用 `globalThis` 缓存？**

Next.js 开发模式下的热重载（HMR）会重新执行模块代码。如果没有 `globalThis` 缓存，每次热重载都会创建新的 `PrismaClient` 实例，导致：
1. 数据库连接数持续增长
2. 最终超出数据库连接限制
3. 出现 "Too many connections" 错误

**为什么用 `PrismaPg` 适配器？**

Next.js App Router 的 Server Component 运行在 Edge-compatible 环境中，直接使用 Prisma 的默认 PostgreSQL 驱动可能不兼容。`@prisma/adapter-pg` 使用 `pg` 包的连接池作为底层，确保兼容性。

### 流式对话

```typescript
export async function* streamChat(options: StreamOptions): AsyncGenerator<string> {
  const response = await fetch(`${OLLAMA_BASE_URL}/api/chat`, {
    method: "POST",
    headers: { "Content-Type": "application/json" },
    body: JSON.stringify({
      model: options.model || DEFAULT_MODEL,
      messages: options.messages,
      stream: true,
      options: {
        temperature: options.temperature ?? 0.7,
      },
    }),
  });

  const reader = response.body?.getReader();
  const decoder = new TextDecoder();

  if (!reader) return;

  while (true) {
    const { done, value } = await reader.read();
    if (done) break;

    const chunk = decoder.decode(value, { stream: true });
    const lines = chunk.split("\n").filter((l) => l.trim());

    for (const line of lines) {
      try {
        const data = JSON.parse(line);
        if (data.message?.content) {
          yield data.message.content;
        }
        if (data.done) return;
      } catch {
        // 忽略解析错误（不完整的 JSON 行）
      }
    }
  }
}
```

```typescript
// 余弦相似度
export function cosineSimilarity(a: number[], b: number[]): number {
  const dot = a.reduce((sum, v, i) => sum + v * b[i], 0);
  const normA = Math.sqrt(a.reduce((sum, v) => sum + v * v, 0));
  const normB = Math.sqrt(b.reduce((sum, v) => sum + v * v, 0));
  return dot / (normA * normB);
}
```

## 六、文本分块 — `src/lib/chunking.ts`

### 接口

```typescript
interface TextChunk {
  content: string;
  metadata: {
    chunkIndex: number;
    documentSource?: string;
    wordCount: number;
    tokenCount: number;
  };
}

interface ChunkConfig {
  chunkSize: number;   // 默认 1000
  overlap: number;     // 默认 200
  minLength: number;   // 默认 100
}
```

### 分块算法详解

```typescript
export function chunkText(text: string, config: ChunkConfig = {}): TextChunk[] {
  const { chunkSize = 1000, overlap = 200, minLength = 100 } = config;

  // 步骤 1: 按段落分割（双换行符）
  const paragraphs = text.split(/\n\n+/).filter((p) => p.trim());

  const chunks: TextChunk[] = [];
  let currentChunk = "";
  let chunkIndex = 0;

  for (const paragraph of paragraphs) {
    // 步骤 2: 处理段落
    if (paragraph.length <= chunkSize) {
      // 段落较短，直接追加
      if (currentChunk.length + paragraph.length > chunkSize) {
        // 当前块已满，保存并开始新块
        if (currentChunk.length >= minLength) {
          chunks.push(createChunk(currentChunk, chunkIndex++));
        }
        currentChunk = paragraph;
      } else {
        currentChunk += (currentChunk ? "\n\n" : "") + paragraph;
      }
    } else {
      // 段落较长，按句子分割
      const sentences = paragraph.split(/(?<=[。！？.!?])\s*/);
      for (const sentence of sentences) {
        if (sentence.length > chunkSize) {
          // 单个句子过长，按字符数切割
          for (let i = 0; i < sentence.length; i += chunkSize - overlap) {
            const subChunk = sentence.slice(i, i + chunkSize);
            if (subChunk.length >= minLength) {
              chunks.push(createChunk(subChunk, chunkIndex++));
            }
          }
        } else if (currentChunk.length + sentence.length > chunkSize) {
          if (currentChunk.length >= minLength) {
            chunks.push(createChunk(currentChunk, chunkIndex++));
          }
          currentChunk = sentence;
        } else {
          currentChunk += (currentChunk ? " " : "") + sentence;
        }
      }
    }
  }

  // 保存最后一个块
  if (currentChunk.length >= minLength) {
    chunks.push(createChunk(currentChunk, chunkIndex++));
  }

  // 添加重叠（overlap）
  for (let i = 0; i < chunks.length - 1; i++) {
    const nextContent = chunks[i + 1].content;
    const overlapText = nextContent.slice(0, overlap);
    chunks[i].content += "\n\n..." + overlapText;
    chunks[i].metadata.tokenCount = Math.ceil(chunks[i].content.length / 4);
  }

  return chunks;
}

function createChunk(content: string, index: number): TextChunk {
  return {
    content,
    metadata: {
      chunkIndex: index,
      wordCount: content.split(/\s+/).filter(Boolean).length,
      tokenCount: Math.ceil(content.length / 4),
    },
  };
}
```

### 上下文增强

```typescript
export function enhanceChunkWithContext(
  chunk: TextChunk,
  documentName: string
): TextChunk {
  // 在块内容前添加来源标注
  chunk.content = `[来源文档: ${documentName}]\n\n${chunk.content}`;
  chunk.metadata.documentSource = documentName;
  chunk.metadata.tokenCount = Math.ceil(chunk.content.length / 4);
  return chunk;
}
```

这样 AI 在收到检索结果时，可以看到每条信息来自哪个文档。

### 分块示例

```
输入文本（2500 字符的文档）:
"第一章：什么是 Docker\n\nDocker 是一个容器化平台...\n\n
第二章：安装 Docker\n\n安装 Docker 的步骤..."

输出（chunkSize=1000, overlap=200）:

Chunk 0 (1000 字符):
"第一章：什么是 Docker\n\nDocker 是一个容器化平台...（到某处截断）"

Chunk 1 (1000 字符):
"（前 200 字符重叠）...继续内容...\n\n第二章：安装 Docker..."

Chunk 2 (500 字符):
"（前 200 字符重叠）...安装步骤的剩余部分..."

重叠的作用：避免关键信息在两个块的边界被切断，确保语义完整性。
```
