# 项目总览 — AI 应用引擎

## 项目简介

本项目是一个基于 Next.js 16 的 AI 应用引擎平台，提供五大核心功能模块：

| 模块 | 路径 | 功能 |
|------|------|------|
| 仪表盘 | `/` | 全局概览、统计数据、系统健康检查 |
| 智能体 | `/apps` | AI Agent 的增删改查，绑定知识库模型 |
| 对话 | `/chats` | 多轮流式对话，支持 RAG 检索增强 |
| 知识库 | `/knowledge` | PDF/Markdown 文档上传、分块、向量化 |
| 工作流 | `/flow` | 可视化 DAG 编排，13 种节点类型的流程引擎 |
| 设置 | `/settings` | 系统配置、用户信息、主题切换 |

## 技术栈

| 层级 | 技术 |
|------|------|
| 框架 | Next.js 16.2.2（App Router） |
| UI 库 | Ant Design 6.3.7 |
| 工作流图 | React Flow 11.11.4 |
| 状态管理 | Zustand 5.0.12（带 persist 中间件） |
| 数据库 | PostgreSQL + Prisma 7.7.0（@prisma/adapter-pg 适配器） |
| AI 推理 | Ollama（本地 LLM，默认模型 `qwen2.5:7b`） |
| 向量嵌入 | Ollama Embedding（默认模型 `nomic-embed-text`，768 维） |
| 样式 | Tailwind CSS v4 |
| 认证 | Cookie Session + bcryptjs |
| 密码哈希 | bcryptjs（盐轮数 10） |

## 数据流向

1. **认证流**: `middleware.ts` 检查 `auth_session` Cookie → 未登录则重定向 `/login` → 登录 API 设置 Cookie → 后续请求自动携带
2. **对话流**: 前端选择 Agent → 发送消息 → API 检查 RAG 知识库 → 调用 Ollama 流式返回 → SSE 推送至前端
3. **知识流**: 上传 PDF/MD → 解析文本 → 分块 → 向量化 → 存入 DocumentChunk 表
4. **工作流流**: 前端 React Flow 画布编排节点 → 保存 → 执行引擎拓扑排序 → 逐层并行执行 → SSE 实时推送进度
