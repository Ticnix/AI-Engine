# 工作流节点详解

本模块是工作流子系统的补充文档，详细介绍 13 种节点的渲染效果、连接规则和配置参数。

## 一、节点通用结构

所有 13 种节点组件都遵循相同的结构：

```typescript
import { memo } from "react";
import { Handle, Position } from "reactflow";
import { SomeIcon } from "@ant-design/icons";
import type { NodeProps } from "reactflow";

interface CustomNodeData {
  label: string;           // 节点名称
  config: Record<string, any>; // 配置数据
}

const SomeNode = memo(({ id, data, selected }: NodeProps<CustomNodeData>) => (
  <div className={`node-card some-node ${selected ? "selected" : ""}`}>
    {/* 目标手柄（顶部入口） */}
    <Handle type="target" position={Position.Top} />

    {/* 节点内容 */}
    <div className="node-header">
      <SomeIcon className="node-icon" />
      <span className="node-label">{data.label}</span>
    </div>
    {data.config.someField && (
      <div className="node-meta">{data.config.someField}</div>
    )}

    {/* 源手柄（底部出口） */}
    <Handle type="source" position={Position.Bottom} />
  </div>
));

export default SomeNode;
```

## 二、13 种节点逐一详解

### 2.1 Trigger — 触发器节点

| 属性 | 值 |
|------|---|
| 类型 | `trigger` |
| 入口 | 无（流程起点） |
| 出口 | 1 个（source，底部） |
| 图标 | ⚡ LightningBoltOutlined |
| 边框色 | 金色 `#faad14` |

#### 配置

```json
{
  "description": "流程的入口，接收初始输入"
}
```

#### 执行行为

```typescript
// 返回 context.inputs（触发器传入的数据）
async function execute(node, context) {
  return { data: context.inputs };
}
```

#### 视觉特征

```
     ┌──────────────────┐
     │   ⚡ 触发器       │
     │   流程入口       │
     └────────┬─────────┘
              │  (唯一的 source 手柄)
              ↓
```

#### 执行行为

```typescript
async function execute(node, context) {
  const { model, systemPrompt, userPrompt, temperature } = node.data.config;

  // 解析变量
  const resolvedSystem = resolveVariablesInString(systemPrompt, context);
  const resolvedUser = resolveVariablesInString(userPrompt, context);

  // 调用 Ollama
  const result = await chat({
    model: model || "qwen2.5:7b",

      { role: "system", content: resolvedSystem },
      { role: "user", content: resolvedUser },

  return {
    data: {
      content: result.content,
      model: result.model,

```

### 2.3 Retrieval — 向量检索节点

| 属性 | 值 |
|------|---|
| 类型 | `retrieval` |
| 入口 | 1 个 |
| 出口 | 1 个 |
| 图标 | 📚 BookOutlined |
| 边框色 | 紫色 `#722ed1` |

#### 配置

```json
{
  "query": "{{input.question}}",
  "topK": 5,
  "threshold": 0.3
}
```

#### 执行行为

```typescript
async function execute(node, context) {
  const { query, topK = 5, threshold = 0.3 } = node.data.config;

  // 解析查询文本
  const resolvedQuery = resolveVariablesInString(query, context);

  // 向量化
  const queryEmbedding = await getEmbedding(resolvedQuery);

  // 查询所有分块
  const chunks = await prisma.documentChunk.findMany();

  // 计算相似度并排序
  const results = chunks
    .map((chunk) => ({
      ...chunk,
      similarity: cosineSimilarity(queryEmbedding, chunk.embedding),
    }))
    .filter((r) => r.similarity >= threshold)
    .sort((a, b) => b.similarity - a.similarity)
    .slice(0, topK);

  return {
    data: {
      results: results.map((r) => ({
        content: r.content,
        similarity: r.similarity,
        document: r.document.name,
      })),
      count: results.length,
    },
  };
}
```

### 2.4 Condition — 条件判断节点

| 属性 | 值 |
|------|---|
| 类型 | `condition` |
| 入口 | 1 个（target，顶部） |
| 出口 | 2 个（source，左侧=True，右侧=False） |
| 图标 | 🔀 BranchesOutlined |
| 边框色 | 橙色 `#fa8c16` |

#### 配置

```json
{
  "expression": "{{input.score}} > 80"
}
```

#### 连接规则

```
         target (top)
            │
        ┌───┴───┐
        │ 条件？ │
        └───┬───┘
       True │    │ False
            │    │
  source   source
  (left)   (right)
```

#### 执行行为

```typescript
async function execute(node, context) {
  const { expression } = node.data.config;
  const result = evaluateCondition(expression, context);

  return {
    data: {
      result,                  // true 或 false
      branch: result ? "true" : "false",
    },
  };
}
```

#### 分支跳过逻辑

```typescript
// 引擎中的跳过判断
function shouldSkip(node, context) {
  if (node.type !== "condition") {
    // 检查上游条件节点的分支
    const incomingEdge = edges.find((e) => e.target === node.id);
    if (incomingEdge?.sourceHandle) {
      const conditionNode = nodes.find((n) => n.id === incomingEdge.source);
      const conditionResult = context.outputs.get(conditionNode.id);
      // 如果当前节点在 False 分支上，但条件结果为 true → 跳过
      if (incomingEdge.sourceHandle === "false" && conditionResult?.result === true) {
        return true;
      }
      if (incomingEdge.sourceHandle === "true" && conditionResult?.result === false) {
        return true;
      }
    }
  }
  return false;
}
```

### 2.5 Output — 输出节点

| 属性 | 值 |
|------|---|
| 类型 | `output` |
| 入口 | 1 个（target，顶部） |
| 出口 | 无（流程终点） |
| 图标 | 📤 ExportOutlined |
| 边框色 | 绿色 `#52c41a` |

#### 配置

```json
{
  "template": "最终结果：{{llm-1.data.content}}",
  "format": "text"
}
```

#### 执行行为

```typescript
async function execute(node, context) {
  const { template, format = "text" } = node.data.config;

  const rendered = resolveVariablesInString(template, context);

  let parsed = null;
  if (format === "json") {
    try {
      parsed = JSON.parse(rendered);
    } catch {
      // JSON 解析失败，保留原始文本
    }
  }

  return {
    data: {
      content: rendered,
      format,
      parsed,
    },
  };
}
```

#### 特殊地位

Output 节点的输出会被执行引擎收集为**工作流的最终结果**：

```typescript
// engine.ts 中
const outputNodes = nodes.filter((n) => n.type === "output");
for (const node of outputNodes) {
  finalOutput[node.id] = context.outputs.get(node.id);
}
```

### 2.6 HTTP — HTTP 请求节点

| 属性 | 值 |
|------|---|
| 类型 | `http` |
| 入口 | 1 个 |
| 出口 | 1 个 |
| 图标 | 🌐 GlobalOutlined |
| 边框色 | 青色 `#13c2c2` |
| 元信息 | 显示 HTTP 方法 |

#### 配置

```json
{
  "method": "POST",
  "url": "https://api.example.com/data",
  "headers": "{\n  \"Authorization\": \"Bearer {{input.token}}\"\n}",
  "body": "{\n  \"query\": \"{{input.query}}\"\n}"
}
```

#### 执行行为

```typescript
async function execute(node, context) {
  const { method, url, headers, body } = node.data.config;

  const resolvedUrl = resolveVariablesInString(url, context);
  const resolvedHeaders = JSON.parse(resolveVariablesInString(headers || "{}", context));
  const resolvedBody = body ? JSON.parse(resolveVariablesInString(body, context)) : undefined;

  const controller = new AbortController();
  const timeout = setTimeout(() => controller.abort(), 30000); // 30秒超时

  try {
    const response = await fetch(resolvedUrl, {
      method,
      headers: resolvedHeaders,
      body: method !== "GET" ? JSON.stringify(resolvedBody) : undefined,
      signal: controller.signal,
    });

    const responseData = await response.json();

    return {
      data: {
        status: response.status,
        statusText: response.statusText,
        body: responseData,
        headers: Object.fromEntries(response.headers.entries()),
      },
    };
  } finally {
    clearTimeout(timeout);
  }
}
```

async function execute(node, context) {
  const { workflowId, inputMapping } = node.data.config;

  // 解析输入映射

### 2.9 Code — 代码执行节点

| 属性 | 值 |
|------|---|
| 类型 | `code` |
| 入口 | 1 个 |
| 出口 | 1 个 |
| 图标 | 💻 CodeOutlined |
| 边框色 | 青绿 `#00ffaa` |
| 元信息 | 显示代码预览（前 30 字符） |

#### 配置

```json
{
  "code": "const result = inputs.data.map(x => x * 2);\nreturn { doubled: result };"
}
```

#### 执行行为

```typescript
async function execute(node, context) {
  const { code } = node.data.config;

  // 将上游节点的输出转换为可访问的对象
  const inputs = context.inputs;
  const outputs = Object.fromEntries(context.outputs.entries());

  // 执行 JavaScript（使用 Function 构造函数）
  const fn = new Function("inputs", "outputs", `"use strict"; ${code}`);
  const result = fn(inputs, outputs);

  return {
    data: { result },
  };
}
```

#### ⚠️ 安全提醒

Code 节点通过 `new Function()` 执行用户输入的 JavaScript 代码，这意味着：
- 可以访问 `inputs` 和 `outputs` 对象
- 如果代码包含恶意逻辑（如 `while(true)`），可能导致无限循环
- 执行超时为 60 秒（由引擎的 `Promise.race` 控制）

#### 配置

#### 执行行为

```typescript
async function execute(node, context) {
  const { iterator } = node.data.config;

  // 解析迭代器
  const resolved = resolveVariable(iterator, context);

  if (!Array.isArray(resolved)) {
    throw new Error("迭代器必须是一个数组");
  }

  // 对每个元素并行执行（这里简化处理，实际会执行子流程）
  const results = await Promise.allSettled(
    resolved.map(async (item, index) => {
      // 执行子流程（如果有）
      return { index, item };
    })
  );

  const succeeded = results.filter((r) => r.status === "fulfilled");
  const failed = results.filter((r) => r.status === "rejected");

  return {
    data: {
      total: resolved.length,
      results: succeeded.map((r) => r.value),
      errors: failed.map((r) => (r as PromiseRejectedResult).reason),
    },
  };
}
```

#### 执行行为

```typescript
async function execute(node, context) {
  const { variableName, expression } = node.data.config;

  // 解析表达式
  const value = resolveVariablesInString(expression, context);

  // 存储到 context.outputs
  context.outputs.set(node.id, { name: variableName, value });

  return {
    data: { variableName, value },
  };
}
```
